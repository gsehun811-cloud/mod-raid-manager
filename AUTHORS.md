# Authors and provenance

Raid Manager is maintained and published by [gsehun811-cloud](https://github.com/gsehun811-cloud).
This repository packages the existing independently developed module; the initial
commit is publication history, not a claim of sole authorship of its dependencies.

The module depends on AzerothCore and mod-playerbots and uses their APIs and world/
BiS data conventions. Generated item/source/proficiency views are derived from
the source snapshot described in NOTICE.md and the JSON provenance manifests.

Upstream author records are retained verbatim:

- [AzerothCore authors](third_party/AZEROTHCORE_AUTHORS.md)
- [Playerbots authors](third_party/PLAYERBOTS_AUTHORS.md)

These files document upstream contributor history; they do not imply endorsement
or that every listed person contributed directly to Raid Manager. The local archive
does not contain recoverable upstream Git history, so individual data-row commit
authors and exact parent revisions are not invented.
